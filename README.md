# password-strength-checker
Simple and interactive password strength checker built with React and Vite.


A responsive and interactive Password Strength Checker built using React.js and Vite.

## Features
- Real-time password criteria validation
- Live score calculation (Weak, Medium, Strong)
- Show / Hide password visibility toggle
- Modern and clean UI with CSS

## Tech Stack
- React.js
- CSS3
- Vite
